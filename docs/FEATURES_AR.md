# الوظائف التقنية | MiniRack

## مكونات التنفيذ الحالي

| النظام | الوظيفة |
|---|---|
| نقطة الاتصال | توصيل الهواتف والأجهزة من خلال ESP32-S3 |
| الربط المنزلي | نفق WireGuard مع Raspberry Pi |
| توجيه البيانات | مشاركة الإنترنت عبر NAT وفق إعدادات المسار |
| HOME-001 | تحقق محلي من صلاحية الوصول وتحديث قواعد السماح |
| إدارة الأجهزة | تسجيل المالك والضيف وإدارة الجلسات من الواجهة |
| الواجهة | عرض حالة الاتصال وأولوية مسارات الشبكة |
| التجارب التكيفية | شيفرة لتصنيف ظروف التشغيل وتجربة اختيار خوارزميات التشفير |

## التجهيز الميكانيكي ومنظومة الطاقة

- تصميم هيكل من سبع قطع STL، مع حيّز مخصص لتركيب بطارية ليثيوم بوليمر.
- موصل تلامس متعدد الأطراف وأسلاك توصيل ضمن تخطيط التجميع الداخلي.
- تكامل دائرة الشحن والحماية وتنظيم الجهد، وتعيين أطراف الموصل، والتحقق من الملاءمة الفعلية خطوات ما زالت قيد التجهيز.

## اتجاهات التطوير

- تكامل حقلي مع وسائل الوصول الخلوي والفضائي.
- التحقق من الاشتراك عبر أنظمة مشغّلين متعددين.
- نقل الجلسات تلقائيًا بين المسارات عند تغيّر التغطية.
- توسيع التحقق الأمني متعدد الطبقات وقياس الأداء.

لا تمثل العناصر المستقبلية ميزات تشغيلية تم إثباتها على شبكة اتصالات تجارية.
