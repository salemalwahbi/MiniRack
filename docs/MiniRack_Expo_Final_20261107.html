03 / التحقق من صلاحية الاشتراك

إعادة عرض نتائج اختبار موثّقة — ليست اتصالًا حيًا

اختبار مختبري سابق على Raspberry Pi باستخدام HTTP وSQLite وHMAC: سُمح لحساب HOME-001 عبر ثلاث هويات بوابات تجريبية (السعودية أرضي، اليابان أرضي، اليابان فضائي ممثل برمجيًا)، ثم رُفض طلب مصادقة جديد عند تعليق الاستحقاق برمز HTTP 403. هذه النتائج لا تثبت تجوالًا دوليًا فعليًا.

اختر نتيجة الاختبار التي تريد عرضها. حالة الاتصال أعلاه مستقلة عن نتيجة المصادقة.

04 / سجل التجربة

حدود الإثبات: الاتصال الآمن الحقيقي بين ESP32 وRaspberry Pi جزء منفصل من نموذج MiniRack الفعلي. هذا العرض يحاكي شبكات الوصول والأبراج والستلايت، وتبديل المسارات وهوية الاشتراك؛ ولا يعمل المسار الفضائي إلا عند تفعيل افتراض وجود تغطية وتصريح خدمة. نتائج المصادقة المعروضة مأخوذة من اختبار مختبري سابق وليست طلبات حية؛ ولا ينشئ اتصالات إنترنت أو ICMP حقيقية، ولا يثبت إمكانية استخدام اشتراك المنزل لدى مشغل آخر دون اتفاقيات أو بنية تحتية داعمة.
