# إعدادات محلية خاصة — لا ترفعها إلى GitHub

المصدر يستخدم ملفات خاصة موجودة في جهاز التطوير وليست ضمن هذا الأرشيف:

- `include/wg_secrets.h` وفيه إعدادات WireGuard ويستدعي `wg_private_local.h`.
- `wg_private_local.h` يحوي المفتاح الخاص، ويتوافر محليًا عبر إعدادات البناء الخاصة.
- `src/minirack-bridge-secrets.h` يُنشأ محليًا ولا يرفع.
- `include/minirack_v2_private.h` يحوي بيانات تجربة تسجيل الجهاز، ولا يرفع.
- نسخ Raspberry Pi من نوع `.tar.gz` أو ملفات IKEv2، مفاتيح التوقيع، وقواعد البيانات لا تُرفع.

النسخة العاملة السابقة محفوظة بشكل مستقل. لا تستخدم ملفات مثال مزيفة على جهاز العرض. لا تدرج المحتوى السري في commits قديمة، ولا يكفي `.gitignore` لإزالة أسرار سبق رفعها.
