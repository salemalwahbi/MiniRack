# سجل التحقق الفني | MiniRack

هذا السجل يميز بين **مشاهدة الاختبار** و**الاستنتاج التقني** دون تعميم النتيجة خارج ظروفها.

| الجانب | المشاهدة المسجلة |
|---|---|
| الاتصال الطرفي | اتصل هاتف بنقطة MiniRack-Secure وتصفح الإنترنت عبرها |
| النفق المنزلي | سُجّلت مصافحة WireGuard وحزم مرور باتجاه الإنترنت عبر بوابة Raspberry Pi |
| HOME-001 | أدى سحب التصريح في الاختبار إلى توقف وصول الهاتف للإنترنت |
| سلوك النفق | توقف تصفح الهاتف عند إيقاف WireGuard وعاد عند إعادة تشغيله |
| إدارة الضيف | عمل التصفح للضيف، ولم تُفتح عناوين HTTP الداخلية التي اختُبرت |
| إعادة التشغيل | عاد اتصال ESP32 بالشبكة وخدمات الإنترنت في التجربة |

## تكامل العتاد

ملفات التصميم تشمل سبع قطع STL. وجود موضع للبطارية والموصل والأسلاك في التخطيط لا يعني إتمام اختبار تركيب الأجزاء أو تغذية الجهاز من البطارية؛ لم تُسجل نتيجة تحقق نهائية لهذين الاختبارين ضمن هذا السجل.

## مجالات التحقق المتقدم

عزل الضيوف على مستوى طبقات الشبكة والمنافذ، واختبارات IPv6 والفشل المتعدد، واستعادة النسخ الاحتياطية عمليًا، والأداء تحت أحمال متنوعة؛ تُعالج ضمن خطة الاختبارات الأوسع.

النتائج تخص بيئة الاختبار الموصوفة، ولا تمثل شهادات اعتماد أمنية أو توافقًا قائمًا مع شبكات المشغّلين.
