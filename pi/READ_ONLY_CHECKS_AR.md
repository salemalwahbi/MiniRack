# فحوصات الراسبيري المطلوبة لاحقًا (قراءة فقط)

الملف هنا للتوثيق، وليس سكربتًا يغيّر إعدادات الراسبيري. احتفظ بمفاتيح VPN وبيانات المصادقة الخاصة.

- `sudo wg show` — تحقق من النفق وتاريخ المصافحة وحركة البيانات (لا ترسل المفاتيح الخاصة).
- `ip -4 route` و`ip -6 route` — راجع مسارات Pi.
- `sysctl net.ipv4.ip_forward` — تحقق هل الجهاز يسمح بالتوجيه (هذا لا يكفي وحده).
- `sudo nft list ruleset` — راجع قواعد NAT والجدار الناري دون تعديلها.
- أثناء اختبار full-tunnel لاحقًا، التقط tcpdump محدودًا على الواجهات مع إخفاء العناوين الحساسة قبل مشاركة المخرجات.

**لا تنفذ قواعد NAT أو IP forwarding جديدة الآن**؛ يجب تصميم نطاقات AP/WG ومصادقة الضيوف قبل تطبيقها. لا يثبت `wg show` وحده أن عملاء Mini Rack يخرجون عبر المنزل.
